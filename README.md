# Abhishek Sharma — Interactive Portfolio

A responsive, user-friendly portfolio built with **HTML, CSS and vanilla JavaScript**.

## Included interactions

- Responsive mobile navigation
- Active section navigation on scroll
- Scroll progress bar
- Scroll-reveal animations
- Animated counters
- Animated skill bars
- Skill filtering
- Project filtering
- Project detail modals
- Expandable experience timeline
- Certificate modal workflow
- Dark/light theme with `localStorage`
- Interactive developer terminal
- Contact form validation + `mailto:` workflow
- Back-to-top button
- Desktop cursor glow
- Accessible labels and reduced-motion support

## Folder structure

```text
portfolio/
├── assets/
│   ├── certificates/
│   ├── images/
│   └── resume.pdf            # add your real resume here
├── css/
│   ├── style.css
│   ├── animations.css
│   └── responsive.css
├── js/
│   └── main.js
├── index.html
└── README.md
```



No npm install or build command is required.
